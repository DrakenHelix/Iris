# Iris 1.0

Iris is a Windows notch with media controls, a timer, a file shelf, per-app volume, add-on tiles, game FPS, and download progress.

## Start Iris

1. Extract the entire ZIP to a folder and open **Iris.exe**.
2. Select your default design and fullscreen design. Iris starts with Black for the desktop and Liquid Glass for fullscreen.
3. Open **Einstellungen → Allgemein** and select **English** if you want the English interface. Iris restarts and opens Settings again.

Click the Iris icon in the Windows notification area to open Settings. The rightmost button on the quick bar opens the same window.

## Updates

Open **Settings → About Iris → Check for updates**. See [updating Iris](UPDATE.md) for details or follow the [quick start guide](QUICK-START.md).

## Keep settings when moving between folders

Quit the old version from the notification area, then start Iris from the new folder. In **Settings → About Iris**, select **Use existing Iris data…** and choose the previous **Iris.exe**. Confirm the data folder, then quit and reopen the new version. Keep the old data folder because the new version uses it in place.

## Use Iris

- **Display** contains size, monitor, horizontal position, and the option to move the closed notch aside after 0.5 seconds.
- **Design** controls the desktop and fullscreen designs independently.
- **Gaming** shows measured FPS for recognized games when Windows grants access to the measurement helper. Use **Grant Windows permission** if needed.
- **Downloads** lets you connect Chrome once. Steam progress is shown when current values are available. If Steam and Chrome are both downloading, Chrome gets the notch’s download slot.
- **Add-ons** lets you assign actions to eight tiles. Right-click or press F2 on a tile to edit it.
