# Updating Iris

Open **Settings → About Iris → Check for updates**. If a newer stable release is available, select **Download and install**. Iris downloads the matching package from GitHub, checks its SHA-256 digest, and closes before applying the update.

- **Installed edition** — Windows may ask for administrator permission. Setup uses the existing installation folder. Iris opens after the upgrade unless Windows requires a restart.
- **Portable edition** — Iris replaces its program files in the existing folder and restarts. Keep the full ZIP contents together in a writable local folder.

Your settings, shelf shortcuts, and tile configuration stay in your data folder. If you move between separate folders, quit the old copy, open the new one, and use **Settings → About Iris → Use existing Iris data…**. Select the old **Iris.exe**, review the folder, and restart. Keep the old data folder because Iris uses it in place.

The original Iris 1.0 download predates the update button. Install the refreshed 1.0 setup or switch to the refreshed portable ZIP once to enable in-app updates.
