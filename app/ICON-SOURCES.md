# Icon sources

The public build uses action symbols and neutral integration artwork. Optional logo resources in private builds are subject to the respective owners' terms.

- Action symbols are adapted from [Microsoft Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) under the included MIT license.
- Discord and Steam icons were extracted from their official Windows clients. [Discord branding](https://discord.com/branding) · [Steam](https://store.steampowered.com/about/)
- The ChatGPT mark comes from the official [OpenAI GitHub organization](https://github.com/openai). [OpenAI brand guidelines](https://openai.com/brand/)
- Spotify and Apple Music use artwork from the [Spotify media kit](https://newsroom.spotify.com/media-kit/logo-and-brand-assets/) and [Apple Music for Windows support](https://support.apple.com/en-us/118290).
- The OBS icon was extracted from official [OBS Studio](https://obsproject.com/) binaries.
- Git, GitHub, and VS Code marks come from the [Git organization](https://github.com/git), [GitHub](https://github.com/logos), and the [VS Code repository](https://github.com/microsoft/vscode).
