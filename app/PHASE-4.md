# Integrations

The tile editor shows available actions and their requirements.

- **Spotify and Apple Music** use supported Windows media controls for playback. Spotify account features require a Spotify connection. Apple Music actions depend on the installed app and its available controls.
- **OBS Studio** uses its WebSocket server. Enter and test the connection details in Iris before using a tile.
- **Browser** actions use the selected browser and its supported shortcuts or URLs.
- **Coding** actions open the selected tools and workflows. Review commands that make changes in the tool that runs them.
- **Hardware and productivity** actions vary by installed apps, configured paths, and Windows support.

Iris stores connection credentials locally. Exported add-on packages contain the tile configuration.
