# Quick start

Run the setup or extract the entire portable ZIP and open **Iris.exe**. Open Settings from the Iris icon in the Windows notification area or the rightmost button in the notch's quick bar.

- **General** controls language and startup. **Display** controls size, monitor, and position.
- **Design** offers Black, Liquid Glass, and Transparent, with a separate fullscreen rule.
- **Music and lyrics** uses the active Windows media session. Cover art and timed lyrics depend on the player and track. Select a timed lyric line to seek.
- **Timer** accepts custom durations, runs while the notch is closed, and alerts you when it finishes.
- **Shelf** holds up to four file or folder shortcuts. Removing a shortcut leaves the original in place.
- **Volume mixer** adjusts individual audio sources. Select an app icon to mute or unmute it.
- **Add-ons** has eight configurable tiles. Right-click a tile or press F2 to edit it. Drag a tile to move or swap it.
- **Gaming** shows measured FPS in supported games. Use **Grant Windows permission** if the measurement helper needs access.
- **Downloads** displays progress from supported sources. Follow the [Chrome setup guide](DOWNLOADS.md) for background Chrome progress.

See [updating Iris](UPDATE.md) for the installed and portable versions.
