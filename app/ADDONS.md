# Add-ons

Open the Add-ons page from the quick bar. Right-click a tile or press F2 to edit it. Drag a tile to move it or swap positions.

- **Windows** provides actions for audio, windows, system settings, folders, and screenshots.
- **Steam and Discord** can launch installed games and use supported desktop actions. See [Steam games](STEAM-GAMES.md) and [Discord](DISCORD.md).
- **Media and productivity** provide actions for players, browsers, coding tools, and local workflows. See [integrations](PHASE-4.md).
- **Custom** tiles can open folders, launch an app, open a website, or send a shortcut to an app.

Use the add-on library to import a package. Importing and saving configure the tile. Actions such as shutdown and restart ask for confirmation. Some integrations need the target app to be running or connected. **Auto** icons use the action's default artwork. [Icon sources](ICON-SOURCES.md)
