# Discord actions

Start the Discord desktop app before using its integration. Iris can request microphone or deafen changes through accessible controls and checks Discord's response before reporting a state change.

For a channel tile, open the relevant server in Discord, edit a tile in Iris, and select **Discord → Open server or channel**. Refresh the picker and expand the server to choose a text channel. The picker shows servers and channels Iris has seen through Discord's interface.

To share your screen, join a voice channel first. The Discord tile opens the screen-sharing picker when its button is accessible. Choose what to share in Discord.
